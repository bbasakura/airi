# Frieren Local Test Model

This slot is reserved for the VRoid Hub model by `Jshan`.

Place the downloaded file here as:

```text
assets/local/frieren/model.vrm
```

The model is for local, personal, non-commercial avatar testing only.
Redistribution and alterations are not allowed, and attribution is required.

`model.vrm` is ignored by Git and must never be committed, uploaded to GitHub,
or bundled in a public installer.
