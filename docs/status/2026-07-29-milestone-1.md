# Milestone 1 Status - 2026-07-29

## Completed

- Created the dedicated `AIRI-Companion` repository.
- Pinned the reviewed AIRI baseline to version `0.11.3` and upstream commit
  `a42e3ae0b51000c552d7cd19e6c20fa10918a614`.
- Added a dependency-free local companion sidecar on `127.0.0.1:17321`.
- Added Tuzi/OpenCodex streamed chat support.

  transcription, speech polling, and Range audio proxying.

## Current Product Level

ready to be consumed by a web UI, AIRI desktop shell, Codex adapter, mobile client,
or digital-human renderer.
